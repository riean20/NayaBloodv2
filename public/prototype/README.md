# NayaBloodv2 local prototype

Static, responsive first-pass website based on the supplied dark brown and gold reference direction.

## Run locally
Open `index.html` in a browser, or from this folder run `python3 -m http.server 8000` and open `http://localhost:8000`. No build step or packages required.

## Collection classification
- The five supplied character artwork cards (Kenji, Luna, Elara, Akame, and Naya) are labeled as the NayaBlood AI Agent NFT collection, per the project owner's clarification that they are recorded on BSC.
- The gallery does not assert any per-image token ID mapping.
- The Item NFT collection is separate and not supplied; no Item NFT artwork was included.
- The AI Agent contract address shown is a candidate address, not verified in this build.
